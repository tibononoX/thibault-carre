# Site de Thibault Carré — sites web pour artisans

Site statique (HTML/CSS/JS, sans étape de build, sans CDN). Polices et images auto-hébergées.

Positionnement : sites rapides, pensés mobile, pour les peintres, menuisiers, paysagistes et couvreurs, conçus pour faciliter les demandes de devis.

Le site est en français, avec une version anglaise sous `en/`.

## Lancer en local

```bash
python3 -m http.server 8000
# FR :     http://localhost:8000/
# EN :     http://localhost:8000/en/
# maquette : http://localhost:8000/demo-artisan/
```

Sur GitHub Pages, l’adresse prévue est `https://tibononox.github.io/thibault-carre/`.
